### 🚀 About Me

- 🔭 I like peeling back the layers of things most people take for granted — like what's really happening inside a built-in string function.
- 🛡️ I build tools like **WebFuzzer** to probe web apps for hidden weaknesses.
- 🧪 `c_sandbox` is my personal lab for experiments, practice, and "what happens if I do *this*?" moments.
- 🌱 Currently sharpening my skills in low-level programming (C) and security tooling (Python).
- ⚡ Fun fact: I'd rather understand *why* something works than just use it.
