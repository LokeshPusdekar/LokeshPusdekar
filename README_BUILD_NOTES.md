# Build notes

This is a GitHub Profile README project, not a separate dashboard website.

The reference structure was based on the inspected Avi Vashishta profile README:
`whoami` → hero artwork → contributions → links.

The Lokesh version expands that terminal concept with:
system info → stack → contribution map → stats → activity → snake → links.

The SVG portrait and wordmark are generated/local assets, while the contribution calendar and snake are generated by GitHub Actions.
